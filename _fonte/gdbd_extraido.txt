A resposta: Catálogo de Dados

===== SLIDE 18 =====
● Virtualization
○ Análises em SQL são interessadas em Tabelas, não em arquivos, padrões de acesso, etc.
○ O Catálogo deve ﬁcar estável com a visão das Tabelas, mesmo que os componentes de análise mudem
● Discoverability
○ Ajuda a descobrir quais conjuntos de dados estão disponíveis para consulta
○ Informação sobre os dados, como dono, frequência de atualização, etc.
● Schema Evolution
○ Registros podem mudar com o tempo, alterando seu esquema de dados
○ Provê a descrição do esquema dos arquivos e os salva ao longo do tempo
○ Acessar os arquivos no esquema de dados corretos
○ Monitorar a validade do esquema e possíveis mudanças
● Performance
○ Mapeia os arquivos de cada tabela em partições
○ Aumenta performance evitando trazer pra memória arquivos desnecessários para consulta
A resposta: Catálogo de Dados

As consultas que utilizarem a partição no ﬁltro (WHERE) devem escanear menos dados.
